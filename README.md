# Сервис бронирования оборудования

Индивидуальный сквозной проект. Текущий этап: ПР1 «Основы Python:
типы данных, операции и настройка рабочего окружения».

## Назначение

Сервис позволяет резервировать оборудование на нужный период, проверять
его доступность и рассчитывать стоимость. Он помогает избежать
пересекающихся бронирований одного устройства.

## Целевая аудитория

Студенты, сотрудники учебных заведений, арендаторы техники и администраторы,
отвечающие за выдачу и исправность оборудования.

## Предметная область

Бронирование и временное использование проекторов, камер, ноутбуков и другой
техники. Пользователь выбирает устройство и период. Бронь допустима, если
пользователь активен, оборудование исправно, период корректен и свободен.

## Основные сущности

| Сущность | Планируемые данные | Связи |
| --- | --- | --- |
| Пользователь | Идентификатор, имя, email, активность, роль | Несколько бронирований |
| Оборудование | Идентификатор, название, описание, исправность, часовой тариф | Несколько бронирований в разные периоды |
| Бронирование | Идентификатор, пользователь, оборудование, период, статус, стоимость | Один пользователь, одно устройство, один период |
| Период | Начало и конец использования | Принадлежит бронированию |

На ПР1 сущности представлены переменными. Классы и модели появятся позднее.
Период задаётся как `[начало, конец)`: следующая бронь может начинаться
ровно в момент окончания предыдущей.

## Основные функции

Реализованы в `main.py`:

1. Проверка корректности периода: `is_period_valid`.
2. Проверка исправности и доступности оборудования с учётом одной
   существующей брони: `is_equipment_available`.
3. Расчёт стоимости: `calculate_cost`. Каждый начатый час оплачивается
   полностью; денежные расчёты выполняются через `Decimal`.
4. Определение результата бронирования с проверкой активности пользователя:
   `get_booking_status`.

Законченный сценарий: Иван Петров бронирует проектор 15.10.2026 с 12:00 до
14:30. Предыдущая бронь заканчивается в 12:00. При тарифе 250 руб./час
бронирование подтверждается, оплачиваются 3 часа, стоимость составляет 750 руб.

Учебная демонстрация использует фиксированные данные и не сохраняет бронь.
Ввод, каталог, отмена, проверка даты относительно текущего времени и обработка
множества бронирований относятся к дальнейшему развитию.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.
Команды PowerShell из корня репозитория:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Если `py` недоступна, используйте полный путь к установленному `python.exe`.
Окружение `.venv` исключено из Git. Настройки запуска VS Code находятся
в `.vscode`; нужны расширения Python и Python Debugger.
