# Отладка

1. В VS Code выбрать интерпретатор `.venv/Scripts/python.exe`.
2. В `services.py` поставить breakpoint на проверке `if not user.is_active`
   внутри `create_booking`.
3. Запустить через F5, в меню выбрать создание брони (пункт 7).
4. Указать пользователя 1, оборудование 1 и период:
   `2026-10-15 12:00` — `2026-10-15 14:30`.
5. В Variables посмотреть `user.name`, `equipment.name`, `period.start`
   и `period.end`. Через F10 пройти проверку доступности и создание объекта.
6. Убедиться, что у нового объекта `booking.user is user`,
   `booking.equipment is equipment`, а `booking.cost` равен 750.

Для поиска ошибки в пересечениях можно временно заменить `<` на `<=`
в методе `Period.overlaps`. Тогда бронь, начинающаяся в момент окончания
предыдущей, ошибочно станет недоступной. Поставить breakpoint на возврате
из `overlaps`, сравнить границы периодов, затем вернуть строгие сравнения.

После исправления:

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 .
```

В `debug_session.txt` сохранён старый протокол отладки ПР1.
Он относится к версии до перехода на классы; для ПР3 используются шаги выше.
